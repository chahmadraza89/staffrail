Next.js Backend Route Handlers (Node.js)

Signed HttpOnly HMAC-SHA256 session cookies (/api/auth/session), double-submit CSRF tokens (/api/auth/csrf), path-scoped RBAC & multipart uploads (/api/data), sandboxed file downloads (/api/files/[...path]), and pure TypeScript PDF generation (/api/audit-pdf).

admin/src/app/api/*

Flutter Multi-Platform Client

Includes responsive Admin and Employee views under lib/ backed by pure-Dart local abstractions (LocalDataStore, LocalAuth, LocalStorage, LocalFunctions) and builds cleanly to Flutter Web with zero Firebase packages.

lib/ · test/

Database-Free Core · Plug In Your Own Database

Every external database and cloud vendor package was decoupled behind clean TypeScript and Dart interfaces so you can run immediately in memory or swap in PostgreSQL, MySQL, SQLite, Supabase, or MongoDB.

Next.js Adapter Boundary

Implement the DataStore interface in admin/src/lib/data/types.ts (getDoc, getCollection, getCollectionGroup, runTransaction, subscribeDoc, uploadFile) and wire it into admin/src/lib/data/server-store.ts in place of the default MemoryDataStore.

Organization Branding via Env Vars

Customize clinic/company name, address, support contact, director signatory, and cookie/CSRF secrets without modifying UI components via admin/.env.example (NEXT_PUBLIC_ORG_*) and lib/core/config/organization_config.dart.
